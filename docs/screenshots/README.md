# Screenshots

The main README shows these files. To update one, replace the PNG with the same name.

Take them on a phone in portrait with sample data (no real balances), light theme unless noted, and
crop nothing: GitHub scales them down. English versions go here; French ones can go in `fr/` with
the same names.

| File | What to show |
|---|---|
| `dashboard.png` | Home: balance, vaults and the quick actions button |
| `add-expense.png` | Adding an expense: the big amount, category and payment method |
| `history.png` | Expense history with the period chips and a few days of expenses |
| `vaults.png` | Savings vaults with progress |
| `budgets.png` | Budgets by category |
| `recurring.png` | Recurring bills and subscriptions |
| `afford-it.png` | "Can I afford it?" with a verdict |
| `insights.png` | Insights or financial health |
| `payment-suggestion.png` | The "Log this purchase?" notification after a payment |
| `widget.png` | The home screen widget |
| `dark.png` | Any screen in dark theme |
